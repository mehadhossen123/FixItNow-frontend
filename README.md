## ✨ Features

- 🎨 **Modern & Responsive UI:** Designed with Tailwind CSS for seamless viewing across Mobile, Tablet, and Desktop screens.
- ⚡ **Fast & Dynamic Server Components:** Built on Next.js App Router for optimal performance, SEO, and SSR/SSG capabilities.
- 🔒 **Role-Based Authentication & Protected Routes:** Automatic post-login redirection (`callbackUrl`) for unauthorized users accessing private pages.
- 📥 **Contact & Inquiry System:** Interactive static & dynamic contact forms connecting clients directly to support.
- 📊 **SaaS Admin Panel:** Professional dashboard interface for admins to review incoming messages, analytics, and service requests.
- 🔄 **Axios Integration:** Centralized API client configured with interceptors and base configurations.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & DaisyUI
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **HTTP Client:** Axios
